Section 2

Twelve rules

Break any of these and the code is wrong even if it runs, passes review and demos well. Everything else in this pack is detail; this page is the standard.

#RuleWhat it prevents
R1Every tenant query is scoped by organization_id, and RLS is enabled and forced on the table.A cross-tenant leak that ends the company.
R2No external effect exists outside the tool gateway. No service calls a provider directly.Untraceable actions and unauditable permissions.
R3No approval, no external effect. Approvals are single-use and bound to a payload hash."Approved 200 emails" becoming 2,000.
R4Money state is written only by the verified webhook handler.A customer marked paid because a model read an email.
R5Suppression is checked inside the send tool, not by the caller.Emailing someone who asked never to be contacted.
R6Every model call writes exactly one model_usage row, including failures and timeouts.Cost that cannot be attributed or explained.
R7Model identifiers live in the registry table, never in code, prompts or fixtures.A provider rename becoming a production outage.
R8Deterministic-first: maths, filtering, scheduling and scoring are code; the model extracts, it does not decide numbers.Non-reproducible results and unexplainable scores.
R9Validate at boundaries only — user input and provider responses. Trust internal calls.Defensive noise that hides real defects.
R10One writer per table. Other services read through an API or a view.Two services disagreeing about the same row.
R11Long work is a job. An HTTP request never waits on a model, a send or a third-party API.Timeouts, retries that duplicate effects, hung dashboards.
R12Every effect carries an idempotency key. Duplicate provider ids must be zero.Double sends and double billing after a retry.
The four failures that actually happen

Not missing features. One: an agent that sends without approval. Two: a query that crosses tenants. Three: a task that runs twice and bills twice. Four: a campaign reported complete that was never delivered. Rules R2, R1, R12 and R6 exist for exactly these; the rest are hygiene.
