Section 5

Data model quick sheet

Every table, every column. If a column is not here it does not exist; add it by revising the spec, not by writing a migration.

Universal columns on every table unless noted: id uuid pk default gen_random_uuid(), created_at timestamptz default now(), and on mutable rows updated_at. Every table marked T also carries organization_id uuid not null references organizations(id) on delete cascade and forced RLS.

5.1 Event catalogue

The only event names the system may emit. Every event carries organization_id, occurred_at, actor_type, actor_id. Emit after commit, never before. No message bodies, no personal data — ids, counts and enums only. Analytics, attribution, the CRM timeline and the weekly digest read from this list and nothing else.
