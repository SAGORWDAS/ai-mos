# AI-MOS v0.6.0 - one-brief marketing team beta

Start campaign preparation from a short business brief. A single transactional operation creates the business/campaign and queued plan; replay reuses it. Fictional samples include an invalid-domain contact and stay sandbox-only.

Connected research now scores and drafts observed contacts into review automatically. Owner opt-in prepares clear inbound replies; follow-up drafts also enter Approvals. The tool gateway routes registered tools into existing guarded workflows. Draft rejection receives exactly one corrective generation. Calendar read availability caches for 45 seconds while booking rechecks.

Adds first/last/linear gross-payment campaign attribution, evidence touchpoints and optional campaign expense links. Adds reviewed WordPress.com/Jetpack articles and LinkedIn member text posts through durable effects. Unknown publishing receipts never trigger duplicate posts. Connection requests are shared per screen and independent reads run concurrently.

Validation: 128 Python tests including 20 native PostgreSQL tests, seven frontend tests, TypeScript, optimized Next build, Ruff, specification and 41-table PGlite isolation checks passed. Running HTTP smoke covers both the original sandbox send and new one-brief graph/replay. Browser verification of the new screens remains outstanding after an automatic URL-confidence safety block. Provider checks use controlled HTTP fixtures, not real accounts.

Coverage: 29 Implemented, 23 Partial, 6 External gate. This is not 99% autonomy, full PDF acceptance or production approval. Paid ads, raster images, full attribution/cost coverage, representative model-quality validation and operational hardening remain. See DAY-ONE.md, PLAN-COVERAGE.md and VERIFICATION-0.6.0.md. Hosted CI is linked in the tagged public release.

# AI-MOS v0.5.0 - automated campaign setup beta

Business details are now explicitly runtime inputs: install the platform without them, save a name-only business profile, and complete facts when starting a campaign.

New Autopilot runs planning, research, strategy, content, reporting, selected-contact drafting and approval preparation after one owner start. Optional connected prospect research reads up to three suggested business pages and imports observed same-domain addresses without inventing marketing permission. Durable jobs, idempotency, tenant isolation, pause, caps and role checks remain enforced.

New connection guidance shows each optional provider, required inputs, status and exact callback address. Credentials stay in private integration configuration. Connecting accounts does not alone certify production readiness.

Validation: 90 tests passed across local regression suites, including 14 native PostgreSQL tests; TypeScript and optimized frontend build passed. Hosted CI results are available on the tagged source commit. Browser QA verified a one-start synthetic campaign completed without per-task approval.

This beta automates preparation and configured workflows. Sending, publication, bookings and financial commitments retain explicit owner controls. Broader production engineering and live provider/business-quality gates remain; see docs/PLAN-COVERAGE.md and docs/AUTOMATION.md. No client or revenue outcome is guaranteed.
