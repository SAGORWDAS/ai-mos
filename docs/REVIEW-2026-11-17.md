## Issues corrected

- Brand edits withdraw affected locally published content and invalidate outstanding decisions. Public routes recheck current factual grounding; unchanged saves preserve publication.
- Canonical URLs use trusted deployment configuration instead of request hosts. Paginated sitemaps exclude private, draft, withdrawn and foreign-workspace content.
- Workspace bootstrap commits identity and data together. Requests bind current user/workspace to the authenticated session; mismatches fail before writes. Cross-tab session changes refresh peer tabs without storing business data locally.
- Upload limits count streaming bytes before buffering oversized requests. PDF parsing works independently of launch working directory.
- Public website reads have total deadlines. Bounded research fails before worker lease expiry, complementing per-request timeouts.
- Narrow layouts wrap long text, constrain grid children, scroll tables internally and size mobile controls. Keyboard skip focus, Autopilot checkbox styling and heading hierarchy were corrected.
- CRM editing preserves the existing-customer basis and the evidence length accepted during import.
- Security headers cover frontend/API responses. The Windows launcher refuses occupied ports before rebuilding running assets.
- Workspace counts use database aggregates and actual successful/simulated effect totals.

Representative qualification/reply/model-quality datasets are incomplete. [PLAN-COVERAGE.md](PLAN-COVERAGE.md) records the exact task status.

Production work includes managed hosting, HTTPS/proxy/cookie configuration, persistent secrets, monitoring/alerts, representative concurrency/load and failure drills, independent security review, broader accessibility/browser testing and operational restore exercises. The PDF child has resource/time limits; it is not an OS security sandbox. `APP_ENV=production` deliberately remains gated.

Business facts and credentials are runtime inputs, unnecessary for installation. They are needed to validate actual campaigns/providers. Connecting them cannot fill missing implementation or guarantee clients, rankings or revenue.
