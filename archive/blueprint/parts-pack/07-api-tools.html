7.3 Intent labels — the closed set

The output of TLS-11 classify_reply. Exactly one primary label per inbound message. No free text, no multi-label, no ad-hoc additions — changing this list means re-running the reply golden set.

Order of operations. Suppression (unsubscribe, complaint) is written before anything else runs. auto_reply and bounce_notice never advance a sequence and never produce a reply. Confidence under 0.70 becomes needs_human regardless of the label the model preferred — the threshold lives in code, not in the prompt.
