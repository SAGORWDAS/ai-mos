Part 7

Data layer

Twenty-eight tables, one database, row-level security on every one of them. This part is the schema contract: if a column is not here, it does not exist.

7.1 Principles

  • UUID primary keys (gen_random_uuid()) so records can be created client-side and merged across environments without collision.
  • organization_id on every tenant table, first column of every composite index, and part of every unique constraint.
  • Timestamps in UTC, timestamptz, with created_at and updated_at on every mutable row.
  • Soft delete only where recovery matters (contacts, brands, content). Hard delete with cascade where the row is meaningless alone (chunks, messages).
  • Enums as lookup tables or check constraints for values that drive behaviour — a status value that is not in the machine's state table is a runtime bug.
  • Money as integer minor units plus currency. Never floating point.
  • JSONB for payloads, not for structure. Anything queried or joined is a column.

7.2 Table definitions — P0 core

Tenancy and access

create table organizations (
  id            uuid primary key default gen_random_uuid(),
  name          text not null,
  slug          text not null unique,
  plan          text not null default 'trial',
  timezone      text not null default 'UTC',
  autonomy_default  text not null default 'L2'
                    check (autonomy_default in ('L1','L2','L3','L4')),
  emergency_stop    boolean not null default false,
  status        text not null default 'active'
                    check (status in ('active','suspended','closed')),
  created_at    timestamptz not null default now(),
  updated_at    timestamptz not null default now()
);

create table users (
  id            uuid primary key default gen_random_uuid(),
  email         citext not null unique,
  name          text,
  auth_subject  text unique,          -- external IdP subject
  last_seen_at  timestamptz,
  created_at    timestamptz not null default now()
);

create table memberships (
  id              uuid primary key default gen_random_uuid(),
  organization_id uuid not null references organizations(id) on delete cascade,
  user_id         uuid not null references users(id) on delete cascade,
  role            text not null check (role in ('owner','admin','member','viewer')),
  created_at      timestamptz not null default now(),
  unique (organization_id, user_id)
);

alter table memberships enable row level security;
create policy tenant_isolation on memberships
  using (organization_id = current_setting('app.current_org')::uuid);

Brand and knowledge

create table brands (
  id                uuid primary key default gen_random_uuid(),
  organization_id   uuid not null references organizations(id) on delete cascade,
  name              text not null,
  website           text,
  positioning       text,
  icp               jsonb not null default '{}',   -- segments, size, industry, signals
  voice             jsonb not null default '{}',   -- tone, banned phrases, examples
  pricing           jsonb not null default '{}',   -- plans[], currency, limits
  approved_claims   text[] not null default '{}',
  prohibited_claims text[] not null default '{}',
  created_at        timestamptz not null default now(),
  updated_at        timestamptz not null default now(),
  unique (organization_id, name)
);

create table brand_documents (
  id            uuid primary key default gen_random_uuid(),
  organization_id uuid not null references organizations(id) on delete cascade,
  brand_id      uuid not null references brands(id) on delete cascade,
  kind          text not null check (kind in ('doc','url','faq','transcript','policy')),
  title         text not null,
  source_uri    text,
  checksum      text not null,
  status        text not null default 'pending'
                  check (status in ('pending','indexed','failed')),
  created_at    timestamptz not null default now(),
  unique (brand_id, checksum)
);

create table brand_chunks (
  id              uuid primary key default gen_random_uuid(),
  organization_id uuid not null references organizations(id) on delete cascade,
  document_id     uuid not null references brand_documents(id) on delete cascade,
  ordinal         int not null,
  content         text not null,
  embedding       vector(1536),
  token_count     int not null,
  unique (document_id, ordinal)
);
create index on brand_chunks using ivfflat (embedding vector_cosine_ops);

Agents, tasks, approvals

create table agents (
  id                uuid primary key default gen_random_uuid(),
  organization_id   uuid not null references organizations(id) on delete cascade,
  role_id           text not null,                  -- AGT-07
  name              text not null,
  manifest_version  int not null default 1,
  model_tier        text not null default 'T1',
  autonomy_ceiling  text not null default 'L2',
  enabled           boolean not null default true,
  config            jsonb not null default '{}',    -- guards, limits, persona overrides
  created_at        timestamptz not null default now(),
  unique (organization_id, role_id)
);

create table tasks (
  id                uuid primary key default gen_random_uuid(),
  organization_id   uuid not null references organizations(id) on delete cascade,
  plan_id           uuid references plans(id) on delete cascade,
  agent_id          uuid references agents(id),
  campaign_id       uuid references campaigns(id),
  type              text not null,                  -- draft_outreach, classify_reply, ...
  status            text not null default 'created'
                      check (status in ('created','ready','running','awaiting_approval',
                                        'succeeded','failed','blocked','cancelled','expired')),
  attempt           int not null default 0,
  idempotency_key   text not null,
  input             jsonb not null,
  output            jsonb,
  error_code        text,
  error_detail      text,
  cost_usd          numeric(12,6) not null default 0,
  started_at        timestamptz,
  finished_at       timestamptz,
  created_at        timestamptz not null default now(),
  unique (organization_id, idempotency_key)
);
create index on tasks (organization_id, status, created_at);
create index on tasks (organization_id, campaign_id);

create table task_dependencies (
  task_id        uuid not null references tasks(id) on delete cascade,
  depends_on_id  uuid not null references tasks(id) on delete cascade,
  primary key (task_id, depends_on_id),
  check (task_id <> depends_on_id)
);

create table approvals (
  id                uuid primary key default gen_random_uuid(),
  organization_id   uuid not null references organizations(id) on delete cascade,
  task_id           uuid not null references tasks(id) on delete cascade,
  action_class      text not null,                  -- send_email, bulk_send, book_meeting...
  payload           jsonb not null,
  payload_hash      text not null,                  -- hash(payload); changing payload voids approval
  requested_by      text not null,                  -- agent role id
  status            text not null default 'pending'
                      check (status in ('pending','approved','rejected','expired','revoked','executed')),
  decided_by        uuid references users(id),
  decided_at        timestamptz,
  expires_at        timestamptz not null,
  created_at        timestamptz not null default now(),
  unique (task_id, action_class, payload_hash)
);

Leads, contacts, messages

create table companies (
  id              uuid primary key default gen_random_uuid(),
  organization_id uuid not null references organizations(id) on delete cascade,
  domain          text not null,
  name            text,
  industry        text,
  employee_range  text,
  country         text,
  enrichment      jsonb not null default '{}',
  source          text not null,
  created_at      timestamptz not null default now(),
  unique (organization_id, domain)
);

create table leads (
  id                uuid primary key default gen_random_uuid(),
  organization_id   uuid not null references organizations(id) on delete cascade,
  company_id        uuid references companies(id),
  contact_id        uuid references contacts(id),
  campaign_id       uuid references campaigns(id),
  status            text not null default 'discovered'
                      check (status in ('discovered','enriched','scored','qualified',
                                        'disqualified','contacted','replied','meeting_set',
                                        'converted','dormant','suppressed')),
  score             numeric(5,2),
  score_model       text,                            -- which scoring version produced it
  source            text not null,
  source_confidence numeric(3,2),
  created_at        timestamptz not null default now(),
  updated_at        timestamptz not null default now()
);
create index on leads (organization_id, status, score desc);

create table suppressions (
  id              uuid primary key default gen_random_uuid(),
  organization_id uuid not null references organizations(id) on delete cascade,
  channel         text not null default 'email',
  address         citext not null,
  reason          text not null check (reason in ('opt_out','complaint','bounce','manual','legal')),
  created_at      timestamptz not null default now(),
  unique (organization_id, channel, address)
);

create table messages (
  id                uuid primary key default gen_random_uuid(),
  organization_id   uuid not null references organizations(id) on delete cascade,
  conversation_id   uuid not null references conversations(id) on delete cascade,
  direction         text not null check (direction in ('outbound','inbound')),
  channel           text not null default 'email',
  provider_id       text,
  subject           text,
  body              text not null,
  status            text not null default 'drafted'
                      check (status in ('drafted','pending_approval','queued','sending',
                                        'sent','delivered','bounced','complained','failed')),
  classification    jsonb,          -- intent, sentiment, confidence, model version
  approval_id       uuid references approvals(id),
  sent_at           timestamptz,
  created_at        timestamptz not null default now()
);
create unique index on messages (organization_id, provider_id)
  where provider_id is not null;

create table audit_logs (
  id              bigserial primary key,
  organization_id uuid not null references organizations(id),
  actor_type      text not null check (actor_type in ('human','agent','system')),
  actor_id        text not null,
  action          text not null,
  subject_type    text not null,

7.3 Migration order

Order is not arbitrary — each step's tables are referenced by the next. Migrations are additive within a phase; a destructive change requires a task that authorises it explicitly.

01 extensions            pgcrypto, citext, vector, pg_trgm
02 organizations, users, memberships, invitations      (PH-1)
03 brands, brand_documents, brand_chunks               (PH-1)
04 integrations, oauth_tokens                          (PH-1)
05 agents, agent_tools, model_registry, model_usage, budgets   (PH-1)
06 plans, tasks, task_dependencies, approvals          (PH-1)
07 companies, contacts, prospects, leads, suppressions (PH-3)
08 campaigns, campaign_assets, sequences, sequences_steps      (PH-3)
09 conversations, messages, outreach_drafts            (PH-3)
10 meetings, availability_rules                        (PH-4)
11 customers, subscriptions, payments, invoices        (PH-4)

13 analytics_events, metric_snapshots, learning_records (PH-2/PH-5)
14 audit_logs, notifications                           (PH-1)
15 views, rollup functions, retention jobs             (PH-5)

7.4 Retention and personal data

DataRetentionRule
Messages and conversations24 monthsPurgeable on request; content redacted for closed conversations after 12 months, metadata retained.
Lead and contact recordsWhile active + 24 monthsDeletion request cascades to messages and suppressions remain — an opt-out must survive a purge, or the business will email someone who asked not to be.
Suppression listIndefiniteDeliberately exempt from deletion. Store the address hash where law requires minimisation.
Model usage24 monthsAggregated after 6 months; no prompt content stored here.
Audit logs24 months minimumAppend-only; exportable per tenant.
Brand documentsUntil deletedDeletion removes chunks in the same transaction.
